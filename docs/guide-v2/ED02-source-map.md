# ED-02 — Source map: критичные утверждения для фактчека (Наталье)

Файл-источник: server/data/final-guide.html (прод)
Правило ED-02: каждое научное/медицинское/историческое утверждение → источник (раздел 12 мастер-плана), либо смягчить/удалить.
Температурная эвристика: «светлая обжарка выше, тёмная ниже» — только как стартовая точка, не закон.
ИТОГО: 15 критичных утверждений (T1–T4, M1–M5, H1–H3, S1–S3) + 1 аналогия (H4 — источник НЕ нужен, в фактчек не включать).

## Порядок для Натальи
1. Сначала критичные к запуску: T1–T3, M1–M5 (медицина — самый рискованный блок для претензий), H3 (раф — на лендинге не фигурирует, но в гайде заявлен как «локальный вклад»).
2. По каждому: claim → URL источника ИЛИ предложение по смягчению формулировки.
3. Результат — в этот же документ (дополнить колонку «Статус»), отчёт Главному.
