# A CUP — Монетизация (MONETIZATION ADDENDUM)

> Дополнение к `docs/A_CUP_MASTER_PLAN.md` §5–6. Источник истины — мастер-план; этот файл фиксирует действующие решения владельца.

## Цены (действующие)
- Core (полный справочник): **499 ₽** — контроль до 50 продаж и 20 отзывов. После — A/B/C-тест 499/690/990 ₽ по revenue per qualified visitor (не по конверсии).
- Реф-скидка: **10%** → 449 ₽ (реф); бонус реферу — цифровой, не наличный cashback до проверки налоговой модели.
- Stars (Telegram): **275⭐** (реф — 149⭐).
- Pro/Toolkit: 1 490 ₽ (гипотеза, после запуска).
- Клуб (recurring): 290–390 ₽/мес. (гипотеза, после запуска).
- Подарочная версия: 990–1 490 ₽ (после запуска).

## Гарантия и возврат (юридически зафиксировано)
- Возврат: **7 дней** (ст. 26.1 ЗоЗПП). «Без вопросов» — запрещено.
- Добровольная гарантия «14 дней» СНЯТА (06.08, коммит 6dd41bc) — единый срок 7 дней во всех каналах.
- Реф-бонус реферу = НПД-доход (учитывать в налоговой модели).

## Экономика (из мастер-плана §5)
- При 499 ₽: после НПД 4% + эквайринг ~3,3–3,8% остаётся ~456–460 ₽ до рекламы/партнёров/возвратов. Точный расчёт — по фактическому income_amount ЮKassa.
- Максимальный CPC при конверсии 3% ≈ 14 ₽ → холодная реклама на 499 ₽ почти невозможна; только organic/partner/high-intent/ретаргетинг.
- Модель LTV на 100 покупателей: ARPU ≈ 846 ₽ (core + bump 20%×390 + Pro 12%×1490 + клуб 10%×299×3мес) — модель, не прогноз; коэффициенты заменяются фактическими после первых когорт.

## НПД-лимит (важно)
- 2,4 млн ₽/год ≈ 4 800 продаж по 499 ₽ (при отсутствии других доходов). При run-rate ~200 000 ₽/мес. или накопленных 1,8 млн ₽ — заранее готовить переход на другую форму бизнеса и платёжный контур. Масштабирование не должно остановиться из-за налогового режима.

## Реферальная механика (§6.4)
- Покупатель получает персональную ссылку; друг — 15% скидка (или 10% по действующей ставке), покупатель — цифровой бонус/кредит.
- Share-карточка результата Coffee Fix без персональных данных.
- Реф-параметры хранит сервер, не перезаписываются последним случайным UTM.

## Платная реклама — только после release-gate
- Точный поиск на диагностические запросы, ретаргетинг по result/demo/checkout (покупатели исключены).
- Без PASS Codex и отдельного release-gate платную рекламу НЕ запускать.
