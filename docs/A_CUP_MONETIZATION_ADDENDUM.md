# A CUP — MONETIZATION ADDENDUM (источник: мастер-план v1.0, § «Целевая модель бизнеса» / §0 «Рекомендуемые решения»)

## Цены и этапы (контрольные точки)
- Старт: **499 ₽** как контроль до 50 продаж и 20 подтверждённых отзывов (не масштабировать трафик до baseline-конверсии).
- Затем: тест **690 ₽ и 990 ₽** — решение по revenue per visitor (не по кликам).
- Реф-программа: скидка реферу 10% (449 ₽) — на лендинг не выносится, работает по ссылке `?ref=`.
- Telegram Stars: 275⭐ (канал оплаты для бота).

## Правила
1. Сначала — ошибки продукта/оплаты/аналитики; до этого платный трафик не масштабировать.
2. Затем — бесплатная диагностика (Coffee Fix) + лендинг с настоящим демо.
3. После запуска — Toolkit, подарочная версия, партнёрские предложения, клуб (повышение среднего чека: на 499 ₽ холодная реклама почти без запаса).
4. Масштабирование — только по выручке на квалифицированного посетителя и окупаемости (LTV ≥ 900 ₽, CAC ≤ 30% LTV — для широкого холодного трафика).
