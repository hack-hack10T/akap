## 2. Правила (один intent = одна страница)

- Кластеры «Зерно», «Метод», «Переменная», «Покупка», «Сенсорика», «Культура», «Подарок» — после запуска (Master Plan 7.3, 24 темы).
- Нет копипаста из платного гайда: страницы пишутся с нуля, дают самостоятельную пользу и ведут в Coffee Fix.
- Перекрёстные ссылки между 3 страницами (кислый↔горький↔водянистый) + на /guide/buy.html как вторичный «справочник».
- CTA на /diagnostic/ (Coffee Fix) — зависимость от LEAD-01; до выхода диагностики ссылка временная (вопрос Главному, §5).
