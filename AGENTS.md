## Продукт

- A CUP — «настрой вкус кофе дома». Продаётся интерактивный справочник (core), бесплатный лид-магнит Coffee Fix (диагностика вкуса), далее Toolkit / лаборатория / клуб.
- Позиционирование: «Помогает за 10 минут понять, почему домашний кофе не получается, выбрать одну корректировку и повторить вкусный результат завтра».
- Продавать не «49 глав о кофе», а интерактивную систему (решение владельца, Master Plan).
- Массовая аудитория: городской любитель кофе 23–45, не профессиональные бариста.

## Правила работы агентов

1. Каждый агент работает в СВОЕЙ ветке, один пакет = одна ветка = одно ревью. Соседние контуры не менять без согласования.
2. Перед работой: прочитать AGENTS.md + docs/A_CUP_PROJECT_STATE.md + релевантные разделы docs/A_CUP_MASTER_PLAN.md (+ docs/A_CUP_MONETIZATION_ADDENDUM.md для вопросов цены/партнёрки).
3. После завершения пакета — независимое ревью через Codex (шаблон: CODEX_REVIEW_PROMPTS.md). Без PASS не сливать в main, не выкатывать прод, не запускать платную рекламу.
4. Приоритеты: сначала ошибки продукта/оплаты/аналитики (Фаза 0), затем Coffee Fix и лендинг с демо, затем тесты цены и трафика. Масштабировать только по выручке на посетителя и окупаемости.
5. Запрещено: фабриковать данные/цифры/отзывы/счётчики; имитировать scarcity и скидки; выдумывать рейтинги; давать медицинские утверждения без источников; копировать контент платного продукта в открытые SEO-страницы.
6. Конфликт задачи с мастер-планом → остановиться и поднять владельцу, не менять стратегию молча.
7. Все отчёты — Главному (Аркадий Петрович Воронцов), не владельцу напрямую.

## DoD (общий)

- Функциональность: happy path, error path, повторное действие, мобильный сценарий (360/390/768/1440).
- Данные: событие появляется один раз, параметры на месте, связь с order/payment.
- Контент: русский, единая терминология, источники, без невидимых плейсхолдеров.
- Доступность: клавиатура, focus, aria, контраст, reduced motion.
- SEO: 200, canonical, sitemap, title/H1/description/OG; платная зона noindex.
- Производительность: LCP ≤2.5с, INP ≤200мс, CLS ≤0.1; TTFB ≤0.8с (цель).
- Безопасность: секреты не в клиенте; токены не в URL; webhook проверяется.
- Передача: change log, тесты, известные ограничения, rollback plan.

## Дизайн-система

- A CUP Digital Experience = продуктовая ясность + тёплая кофейная материальность + сдержанное кинематографичное движение (A_CUP_AI_Design_System.md).
- Mobile-first 390×844; контент работает без JS; максимум 6–8 секций; без обязательного hover; без скрытия контента opacity:0 до скрипта; safe areas.
