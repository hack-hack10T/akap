# CODEX_REVIEW_PROMPTS.md — шаблон независимого ревью A CUP

> Собрано из мастер-плана 2026 + процедуры N3 (независимая проверка через Codex).
> Каноническая папка ChatGPT Library «A_CUP_Codex_Context» сверяется при появлении доступа.

## Как использовать

- Запуск: `codex exec --sandbox read-only` (первый проход БЕЗ правок) в корне /home/hack/akap.
- Один пакет = одна ветка = одно ревью. Diff: `git diff main...<ветка>`.
- Результат: вердикт PASS / CHANGES REQUIRED / BLOCKED + P0/P1/P2 + статус каждого DoD + разрешение на merge.
- CHANGES REQUIRED → автор исправляет все P0/P1 → повторное ревью с новым commit/diff.
- Задача завершена только после PASS. Без PASS — нет merge в main, нет прод, нет платной рекламы.
